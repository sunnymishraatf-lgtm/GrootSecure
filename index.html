Security, out of the box

Every layer hardened at build time — verified in the final image.

🛡️ Firewall on

ufw enabled at boot: deny all incoming, allow outgoing. Graphical manager gufw included.

🔒 Kernel locked down

Hidden kernel pointers (kptr_restrict=2), unprivileged eBPF disabled, restricted perf & ptrace, no setuid core dumps.

🌐 Network hardened

SYN cookies, reverse-path filtering, no ICMP redirects or source routing, broadcast ping ignored, martians logged.

⛓️ AppArmor enforced

Mandatory access control active with shipped profiles in enforce mode.

🔄 Auto security updates

unattended-upgrades installed — security patches download and apply daily, silently.

🚫 No SSH server

No OpenSSH server ships — zero remote-login attack surface out of the box.

👤 Login hardened

LightDM guest sessions disabled. Strong password quality rules via libpam-pwquality.

📄 Auditable

Full hardening notes ship at /etc/grootos-secure/HARDENING.md on every system.

Get GrootSecure

3.3 GB ISO, split into 4 parts for easy download.

  1. Download all 4 parts from the v1.0 release page.
  2. Join them into the ISO: 
    cat gs-part-* > GrootSecure-22.2-cinnamon-64bit.iso
    Windows CMD: copy /b gs-part-aa+gs-part-ab+gs-part-ac+gs-part-ad GrootSecure-22.2-cinnamon-64bit.iso
  3. Verify integrity: 
    sha256sum -c GrootSecure-22.2-cinnamon-64bit.iso.sha256
  4. Write to USB with Rufus / balenaEtcher, or boot it in VirtualBox (4 GB RAM, 25 GB disk).
  5. On install, tick "Encrypt the new installation" for full-disk encryption.
